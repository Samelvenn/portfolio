Résumé du projet

Ce projet consiste à réaliser une application mobile Android en Java afin de mettre en pratique les connaissances apprises en cours. Le choix était libre, pour ma part je suis parti sur une aplication de gestion de club de tennis. Il y a donc plusieurs vues, qui font différentes actions.

Cahier des charges

Objectifs

-Créer une application fonctionnelle correspondant aux critères du cahier des charges.

Ce que j'ai réalisé

-Une application mobile Android

-Création de classes et de méthodes en Python.

-Intéraction entre base de données et script Python.

-Une documentation et exmplication de la validation des critères.

Les fonctionnalités

Navigation entre différentes vues.

Visualiser une liste d'objet.

Création d'un formulaire.

Consultation du formulaire.

Les outils utilisés

Pour se projet j'ai utilisé Java. J'ai manipulé l'éditeur de code Android studio.

Résultats

Une application fonctionnelle sur le thème choisi qui permet de créer des entrainements et en visualiser une liste.
