Résumé du projet

Ce projet consiste à réaliser une application locale qui permet d'analyser des données fournies par un logiciel de l'entreprise sous format json afin de faciliter la visualisation de ces données notamment pour les managers. Cette application a été réalisé en Python avec la bibliothèque Streamlit pour l'affichage des données. Pour des mesures de confidentialités, aucun code ne sera mis à disposition.

Objectifs

-Créer une application utilisable et qui répond aux besoins.

-Réagir aux conseils et au cachier des charges évolutifs en fonction de l'avancement du projet.

-Créer la documentation du code pour faciliter la reprise de développement.

Ce que j'ai réalisé

-Analyse de données.

-Parcours de fichier json pour récupérer les données.

-Création de graphiques pour consulter plus facilement l'évolution des coûts.

-J'ai participé à des réunions ou alors effectué des présentations de mon projet au sein de l'entreprise

-Réalisation d'une documentation.

-Réalisation d'un rapport de stage.

Les fonctionnalités

Mise en place d'une chartre graphique.

Consultation des données via des tableaux de données.

Consultation des données via des graphiques.

Graphique camembert dynamique.

Tri par type de données.

Anonymisation de certaines données selon la politique de RGDP.

Les outils utilisés

Pour se projet j'ai utilisé Python. J'ai manipulé l'éditeur de code VS Code avec plusieurs bibliothèques comme streamlit, json, pandas, altair, faker et numerize.

Résultats

L'application est fonctionnelle en local et répond au besoin initial avec plusieurs pages pour consulter les données et une application qui peut servir pour chaque période tant que la structure du fichier json ne change pas.
