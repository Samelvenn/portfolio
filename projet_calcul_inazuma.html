Résumé du projet

Ce projet consiste à réaliser une interface python Tkinter qui utilise des classes en Python. Les classes ont pour but de comparer des statistiques.

Objectifs

-Prendre en main et s'initier à la POO en Python.

Ce que j'ai réalisé

-Une interface Tkinter simple avec quelques composants.

-Création de classes et de méthodes en Python.

-Intéraction entre base de données et script Python.

Les fonctionnalités

Ajout de joueurs.

Comparaison de stats.

Liste des joueurs avec leurs stats.

Les outils utilisés

Pour se projet j'ai utilisé Python. J'ai manipulé l'éditeur de code VS code avec la bibliothèque sqlite pour la connexion entre Python et la BDD.

Résultats

Une interface Tkinter avec des fonctionnalités de bases pouvant influer sur la base de joueurs.
