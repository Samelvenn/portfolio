Résumé du projet

Ce projet consiste à réaliser une application de gestion de salarié avec une base de données.

Cahier des charges

Objectifs

-Mettre en place une application fonctionnelle.

-Développer une interface.

-Lier du code Java à une base de données SQL.

Ce que j'ai réalisé

-Extraction des données des utilisateurs via un script Powershell sur des fichiers CSV.

-Création de script Python pour extraire les données des utilisateurs depuis des fichiers CSV.

-Génération de mots de passe aléatoires pour les nouveaux utilisateurs via des scripts Python.

-Implémentation dans une base de données SQL.

-Réalisation de tests et corrections des différents bugs survenus.

Les outils utilisés

Pour se projet nous avons utilisé Java et SQL. Nous avons manipulé les outils suivants qui sont MariaDB, NeatBeans et également Xampp.

Résultats

Le projet fournit une interface fonctionnelle qui permet de pouvoir consulter les informations d'une base de données via l'interface ainsi que certaines fonctionnalités tel que l'ajout ou la consultation de profil.

Compétences acquises

-Collecter, suivre et orienter des demandes

-Analyser les objectifs et les modalités d organisation d un projet

-Planifier les activités

-Évaluer les indicateurs de suivi d un projet et analyser les écarts

-Réaliser les tests d intégration et d acceptation d un service

-Déployer un service

-Mettre en place son environnement d apprentissage personnel

Etape 0 - Constitution des équipes

Durant cette étape nous avons constituer le choix des duos ainsi que mis en place les éléments d'organisation poru le travail en équipe

Etape 1 - Prise en main de l'existant

Dans cette première étape, l'objectif est de prendre en main les ressources données au début du projet et également de mettre en place la base de donnée

Etape 2 - Compléter les classes métier

Dans cette deuxième, nous avons coder et compléter en java les différentes classes.

Etape 3 - Maquettage d'une interface graphique

Dans cette troisième étape, nous avons mis en place des interfaces graphiques pour les différentes fonctionnalités qui vont arriver dans le futur.

Etape 4 - Classes d'accès aux données (DAO)

Dans cette étape, nous avons réaliser les classes DAO qui permettent d'accéder à la base de données et de réaliser des actions dessus comme la lire.

Etape 5 - Fonctionnalité de consultation des salariés d'un service

Durant cette étape, nous avons réaliser du code qui permet de filtrer la liste des salariés en fonction de leur service.

Etape 6 - Fonctionnalité de consultation des données relatives à un salarié

Dans cette étape, nous avons réaliser un bouton qui permet de lire les données d'un utilisateur sélectionner sur une autre interface.

Etape 7 - Fonctionnalité de suppresion d'un salarié

Dans cette étape, nous avons ajouter le fonctionnalité de pouvoir supprimer un salarié

Etape 8 - Fonctionnalité d'ajout d'un nouveau salarié

Dans cette étape, nous avons ajouter le fonctionnalité de pouvoir ajouter un salarié

Etape 10 - Livraison d'un exécutable

Dans cette dernière étape nous nous sommes occuper de mettre en place l'éxecutable de l'application ainsi que sa documentation.
